# 動画ストリーミングサービス

## 概要
このプロジェクトは、動画ストリーミングサービスです。デザインは概ねYouTubeです。
動画はスマホから見る想定で、縦長のレイアウトを持ち、動画再生時は横に倒してフルスクリーンに切り替えられるようにします。

## 機能

### フロントエンド
- [x] 動画を再生する機能
- [x] 動画一覧表示機能（YouTube風カードレイアウト）
- [x] レスポンシブデザイン（モバイル：縦1列、デスクトップ：2-4列グリッド）
- [x] 動画をアップロードする機能
- [ ] 動画を検索する機能

### バックエンド
- [x] 動画を配信する機能（HLS ストリーミング）
- [x] 動画一覧API
- [x] 動画メタデータAPI
- [x] 動画をアップロードする機能

## 仕様
- [x] 動画はHLSで配信されます
- [x] 動画をアップロードすると、バックエンドはこれをバックグラウンドでHLSに変換します
- [x] 動画はスマホから見る想定です
- [x] 動画のアップロードはPCから行う想定です

## フロントエンド機能

### 動画一覧表示機能
- **YouTube風カードレイアウト**: サムネイル、タイトル、メタデータを含むカード表示
- **レスポンシブグリッド**: モバイル（1列）、デスクトップ（2-4列）の自動調整
- **Next.js App Router**: `/`（一覧）と`/videos/[id]`（個別）の明確な URL 分離
- **ホバーエフェクト**: カードにマウスオーバーで再生ボタンが表示
- **ローディング状態**: スケルトン UI による読み込み表示
- **エラーハンドリング**: API エラー時の適切なフォールバック表示
- **変換ステータス表示**: 変換中の動画は特別な表示（スピナー、クリック不可）
- **自動更新**: 変換中の動画がある場合、5秒ごとに状態を更新

### 動画プレーヤー機能
- **HLS ストリーミング再生**: HLS.js による適応的品質調整
- **モバイル対応**: スマートフォン縦向きレイアウト最適化
- **フルスクリーン再生**: タップで横向きフルスクリーン切り替え
- **エラーハンドリング**: ネットワークエラー・メディアエラーの自動復旧
- **レスポンシブデザイン**: デスクトップ・タブレット・モバイル対応
- **ネイティブコントロール**: ブラウザ標準の再生コントロール

### 動画アップロード機能
- **専用アップロードページ**: `/upload` での動画アップロード
- **ファイル選択**: ダイアログとファイルパス入力の両方に対応
- **タイトル設定**: カスタムタイトルまたはファイル名自動使用
- **アップロード進捗**: ローディング表示とエラーハンドリング
- **重複チェック**: SHA256ハッシュによる同一動画の検出
- **バックグラウンド変換**: アップロード後、自動的にHLS形式へ変換

### 使用方法

#### 動画の視聴
1. `http://localhost:3000` にアクセス
2. 動画一覧（YouTube風カードレイアウト）が表示される
3. 任意の動画カードをクリック/タップ（変換完了したもののみ）
4. 個別動画ページ（`/videos/[id]`）で動画が再生される
5. フルスクリーンボタンで横向き全画面表示
6. 「Back to Videos」ボタンで動画一覧に戻る

#### 動画のアップロード
1. トップページ右上の「Upload Video」ボタンをクリック
2. `/upload` ページで動画ファイルを選択
3. 必要に応じてタイトルを入力（空欄の場合はファイル名を使用）
4. 「Upload Video」ボタンでアップロード開始
5. アップロード完了後、自動的にトップページへ遷移
6. 変換中の動画は「Converting...」と表示され、完了後に視聴可能

## API エンドポイント

### 現在実装済み
- `GET /api` - Welcome message and status
- `GET /api/health` - Health check endpoint
- `GET /api/videos` - 動画一覧取得（videos配列とcount、status含む）
- `GET /api/videos/:videoid` - HLS manifest file (.m3u8) for video streaming
- `GET /api/videos/:videoid/:filename` - HLS segment files (.ts, .vtt, .m3u8)
- `GET /api/videos/:videoid/info` - Video metadata (id, title, hlsUrl, status)
- `POST /api/upload` - 動画アップロード（multipart/form-data）
- `GET /api/conversion-status/:videoid` - 個別動画の変換ステータス
- `GET /api/conversion-status` - 全変換ジョブ一覧

### フロントエンド・バックエンド連携
- フロントエンド: `http://localhost:3000`
- バックエンド: `http://localhost:4000`
- Next.js の rewrites 機能により、フロントエンドの `/api/*` へのリクエストは自動的にバックエンドにプロキシされます

## 開発環境のセットアップ

### 必要な環境
- Node.js 18以上
- ffmpeg（動画変換用）

### インストールと起動

```bash
# フロントエンドの起動
cd frontend
npm install
npm run dev

# バックエンドの起動（別ターミナル）
cd backend
npm install
npm run dev
```

### 注意事項
- アップロードされた動画は `backend/uploads/` に一時保存されます
- 変換済み動画は `backend/videos/<video-id>/` に保存されます
- データベースファイルは `backend/videos.db` に作成されます
- 最大アップロードサイズは5GBに設定されています
