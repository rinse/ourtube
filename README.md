# 動画ストリーミングサービス

## 概要
このプロジェクトは、動画ストリーミングサービスです。デザインは概ねYouTubeです。
動画はスマホから見る想定で、縦長のレイアウトを持ち、動画再生時は横に倒してフルスクリーンに切り替えられるようにします。

## 機能

### フロントエンド
- [ ] 動画を再生する機能
- [ ] 動画を検索する機能
- [ ] 動画をアップロードする機能

### バックエンド
- [ ] 動画を配信する機能
- [ ] 動画をアップロードする機能

## 仕様
- [ ] 動画はHLSで配信されます
- [ ] 動画をアップロードすると、バックエンドはこれをバックグラウンドでHLSに変換します
- [ ] 動画はスマホから見る想定です
- [ ] 動画のアップロードはPCから行う想定です

## 技術スタック

### フロントエンド
- [x] React (Next.js 15.3.5)
- [x] TypeScript
- [x] npm

### バックエンド
- [ ] Express.js
- [ ] TypeScript
- [ ] SQLite3（検索用情報）
- [ ] ファイルシステム（動画保存）
- [ ] ffmpeg（HLS変換）
- [ ] npm

### アーキテクチャ
- [ ] DI（依存性注入）を用いて、動画の保存場所やDBは差し替えられる設計
- [ ] 動画のIDには動画のSHA256ハッシュ値を使用
- [ ] DBのテーブルは少なくとも動画タイトルと動画IDを保持
